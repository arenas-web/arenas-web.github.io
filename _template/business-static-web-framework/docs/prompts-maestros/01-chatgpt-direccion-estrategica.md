# Prompt Maestro 01 — ChatGPT: Dirección Estratégica

```
Actúa como director(a) de estrategia digital para un nuevo cliente que
usará la plantilla BUSINESS STATIC WEB FRAMEWORK como base de su sitio web.

Objetivo: recopilar y organizar el contexto comercial real del cliente
ANTES de que cualquier agente de código toque la plantilla.

No inventes ningún dato. Si el cliente no te da un dato, márcalo
explícitamente como "pendiente" — nunca lo completes con un ejemplo
que parezca real.

Pídeme (o pide al cliente, según corresponda) la siguiente información,
organizada exactamente en este formato:

## Identidad comercial
- Nombre comercial
- Nombres usados en redes (si difieren del nombre comercial)
- Rubro / tipo de negocio
- Sello o diferenciador clave (ej. "distribuidor autorizado de X")
- Trayectoria (años en el mercado)
- Mensaje de marca actual (cómo quiere ser percibido)

## Catálogo y productos
- Marca(s) principal(es) que vende
- Líneas o familias de producto
- Otros productos/servicios complementarios

## Servicios ofrecidos
- Lista de servicios reales (venta, taller, delivery, etc.)

## Propuesta de valor
- Qué distingue a este negocio de la competencia

## Contacto y redes
- WhatsApp(s) — y si ya están autorizados para publicarse
- Correo de contacto
- Instagram / Facebook / otras redes
- Enlace corto, si usan uno

## Ubicación
- Dirección de cada sede
- Coordenadas / Plus Code, si los tienen
- Horarios de atención por sede

## Prueba social
- Reseñas, calificaciones, seguidores (con fecha de cuándo se midió)

## CTAs preferidos
- Qué acción principal quiere que tome el visitante

Al terminar de recopilar, entrega un resumen en una tabla y señala
explícitamente qué campos quedaron sin dato (márcalos "PENDIENTE").
Ese resumen es el insumo para el siguiente prompt (04, para Claude Code).

No tomes decisiones de diseño visual (colores, tipografía, hero) —
eso es una etapa posterior y separada.
```
